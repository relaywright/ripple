# RIPPLE

Use plain language in product copy and explain model assumptions honestly. This is a synthetic single-product educational simulation, not live logistics intelligence or an operational forecast.

TypeScript + React + Vite. Run `npm run check`, `npm run build`, and `npm run test:e2e` before release. Keep the simulation pure, deterministic, and independent of React. Never represent animation as measured shipment positions. No secrets, external API keys, accounts, tracking, or runtime network dependencies.

Design authority: `docs/design-system.md`. Prefer local assets, accessible controls, keyboard navigation, reduced motion, and responsive layouts. Preserve reproducible exports and validate imported scenarios at the boundary.
